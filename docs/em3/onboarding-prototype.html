What the system decided

Two screens ask the person for a decision; the third is progress and does not count as a step under the frozen definition. Mirrors select_backend() in sandbox/contract.py. A refusal that reaches this screen without a usable next step is a contract violation, not a design mistake.

Where unprotected execution went

An older setting can still run other people’s code directly on this computer. It is not part of this flow: nothing here selects it, nothing offers it as a way out, and no screen calls it protected. It stays where it already is, marked as an outdated compatibility setting, until it is migrated on its own.

A genuinely controlled host execution would need a separate privileged process with an authenticated channel — not a switch in a library.

What this prototype is for. It exists to be walked through by ten non-technical people against the fixed protocol in the EM-3 scope: one sentence of instruction, no help, no documentation, and two questions afterwards about where the code ran.

No agent runs here and nothing is sent anywhere. The words "Docker", "container", "MicroVM" and "egress" appear nowhere on the person's side of the screen — only in this note and in the panel you can fold away.
